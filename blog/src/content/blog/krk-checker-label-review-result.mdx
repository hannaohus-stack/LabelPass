식품 라벨을 만들고 나면 "이게 법적으로 문제없는지" 확인할 방법이 마땅치 않습니다. 식약처에 직접 묻기도 어렵고, 디자이너는 법 기준을 알지 못합니다. KRK Checker는 라벨을 업로드하면 의무 표시사항·강조표시·원재료 표기 등을 항목별로 점검해, 무엇을 왜 고쳐야 하는지 근거와 함께 알려줍니다. 검토 결과가 실제로 어떻게 구성되는지 정리했습니다.

## 1. 검토 결과는 어떤 항목으로 구성되나

KRK Checker의 검토 결과는 '통과·실패' 이분법이 아니라, 4개 영역으로 나눠 항목별 기준과 근거를 함께 제시합니다.

| 영역 | 점검 내용 | 근거 |
|---|---|---|
| ① 의무 표시사항 누락 | 식품표시광고법 9가지 항목의 충족 여부, 누락 시 해당 법조항 표시 | 시행규칙 별표4 |
| ② 표기 형식 점검 | 원재료명 함량순, 알레르기 표기 위치, 영양성분표 형식 등 | 표시기준 고시 |
| ③ 강조표시 추가 의무 | 강조표시가 있을 때 발생하는 영양성분표·기준치 충족 의무 | 시행규칙 별표4 |
| ④ 기준 출처 분류 | 항목별 근거 법령·고시를 출처별로 구분 표시 | 표시광고법·고시·자원재활용법 |

핵심은 ②번입니다. 내용이 다 들어 있어도 형식(순서·위치·크기)이 틀리면 위반인 경우가 많은데, 이 형식 오류를 항목별로 잡아주는 것이 검토의 실질적 가치입니다.

## 2. 결과를 실무에 적용하는 3단계

검토 결과 리포트는 받은 순서대로 처리하면 효율적입니다.

**1단계 — 누락 항목 우선 보완.** 의무 표시사항이 빠지면 판매 자체가 불가합니다. 가장 먼저 채웁니다.

**2단계 — 형식 오류 수정.** 원재료 순서, 알레르기 표기 위치, 영양성분표 형식 등은 내용 변경 없이 디자인 수정만으로 해결됩니다.

**3단계 — 디자이너에게 리포트 전달.** 점검 결과를 그대로 공유하면 수정 항목을 정확히 전달할 수 있어, 시안 왕복으로 생기는 소통 비용이 줄어듭니다.

## 3. 검토 결과로 알 수 없는 것 — 한계와 주의

KRK Checker 결과는 참고용 자료입니다. 최종 판단은 담당 공무원이나 식품 전문가의 확인이 필요합니다. 특히 다음 경우는 추가 확인을 권합니다.

- 신규 품목으로 식품유형 분류가 불명확한 경우
- 원재료가 복잡하게 혼합된 복합 원재료인 경우
- 기능성 표시 식품·건강기능식품에 해당하는 경우

이 세 경우는 자동 점검만으로 판정이 어렵습니다. 검토 결과를 1차 필터로 쓰고, 최종 출고 전 전문가 확인을 한 번 더 거치는 흐름을 권장합니다.

## 4. 자주 하는 실수

**실수 1. 검토 결과를 '합격증'으로 오해** — 결과는 점검 리포트지 법적 보증이 아닙니다. 누락·형식 오류를 잡아주지만, 최종 책임은 표시 의무자에게 있습니다.

**실수 2. 누락만 고치고 형식 오류는 방치** — 의무 항목을 다 채웠어도 순서·위치·크기 형식이 틀리면 위반입니다. ②번 형식 점검 결과까지 반영해야 합니다.

**실수 3. 원재료 확정 전에 검토** — 원재료가 바뀌면 원재료명·원산지·알레르기 표시가 연쇄로 바뀝니다. 원재료를 확정한 뒤 검토해야 재작업이 없습니다.

## 5. 검토 전 준비 체크리스트

✅ 라벨 파일 준비 (PDF 또는 고해상도 이미지)

✅ 원재료 구성·배합비 확정 (검토 전 필수)

✅ 강조표시 사용 계획 여부 정리

✅ 사용 포장재 재질 목록 (분리배출 마크 점검용)

✅ 검토 후: 누락 → 형식 → 디자이너 전달 순으로 처리

✅ 출고 전: 복합 원재료·기능성 해당 시 전문가 확인 추가

## 6. 자주 묻는 질문

**Q. 어떤 파일 형식으로 올려야 하나요?**
라벨 표시면이 또렷하게 보이는 PDF 또는 고해상도 이미지면 됩니다. 글자가 흐리면 형식(글자 크기·장평) 점검 정확도가 떨어질 수 있습니다.

**Q. 검토 결과만 있으면 바로 판매해도 되나요?**
검토 결과는 1차 점검 리포트입니다. 신규 품목·복합 원재료·기능성 표시처럼 판정이 복잡한 경우에는 출고 전 전문가나 관할 기관 확인을 한 번 더 권장합니다.

**Q. 디자인이 아직 안 나왔는데 검토할 수 있나요?**
표시사항 텍스트가 확정돼 있으면 텍스트 기준 점검이 가능합니다. 다만 글자 크기·위치 등 형식 항목은 디자인 시안이 나온 뒤 다시 확인하는 것이 정확합니다.
