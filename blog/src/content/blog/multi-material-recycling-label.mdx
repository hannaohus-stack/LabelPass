잼 병, 음료 병, 소스 용기처럼 본체와 뚜껑의 재질이 다른 경우, 분리배출 마크도 각 재질마다 표시해야 합니다. "본체에만 붙이면 된다"고 생각해 뚜껑 표시를 빠뜨리는 경우가 흔한데, 이는 표시 위반입니다. 환경부 분리배출 표시 지침을 기준으로 복합·다중포장재의 표시 방법을 정리했습니다.

근거: 「분리배출 표시에 관한 지침」(환경부고시 제2024-170호) 제5조(다중포장재 표시)·제6조(일괄표시)

## 1. 복합·다중포장재 표시 원칙

재질이 다른 포장재가 결합된 경우, 분리배출 표시에 관한 지침 제5조에 따라 **분리되는 각 부분품마다 분리배출 표시를 하는 것이 원칙**입니다.

- 각 재질마다 해당 분리배출 마크를 표기
- 소비자가 어느 부분을 어떻게 분리 배출하는지 인지할 수 있도록 표기
- 같은 재질이어도 구성 부분이 여러 개면 모두 표시 (재질이 같다는 이유로 생략 불가)

핵심은 "본체 따로, 뚜껑 따로"가 기본이라는 점입니다. 유리병 본체와 플라스틱 뚜껑은 분리 배출 방법이 다르므로, 각각 마크가 필요합니다.

## 2. 각각 표시할까, 일괄표시할까 — 판단 기준

지침 제6조의 일정 조건을 충족하면 **일괄표시**가 가능합니다. 일괄표시란 주요 구성 부분 한 곳에 분리배출 표시를 하고, 그 표시 상하·좌우 인접한 곳에 다른 구성 부분의 명칭과 재질명을 한꺼번에 기재하는 방식입니다.

- 부분품이 명확히 분리되고, 표기 공간 확보가 어려운 경우 → 일괄표시 검토
- 일괄표시 세부 기준은 별도로 규정돼 있지 않으므로, 제품·포장재 여건에 맞게 소비자가 식별하기 쉽도록 기재하면 됩니다.

다만 일괄표시도 "모든 구성 부분의 재질을 빠짐없이 적는다"는 원칙은 동일합니다. 표기 방식이 달라질 뿐 표시 대상이 줄어드는 것은 아닙니다.

## 3. 케이스별 표기 방법

**케이스 1 — 유리병 + 플라스틱 뚜껑**
- 유리병 본체: 유리류 마크 / 플라스틱 뚜껑: 합성수지류 마크
- 라벨 하단에 두 마크를 나란히 표기하거나, 일괄표시 방식으로 정리

**케이스 2 — 종이박스 + 비닐 내장재**
- 종이박스: 종이류 마크 / 비닐(PE·PP 등): 합성수지류(비닐류) 마크
- 박스 표면과 내장재에 각각 표기

**케이스 3 — 캔 + 종이 라벨**
- 캔 본체: 철캔 또는 알루미늄캔 마크
- 종이 라벨: 일반적으로 캔과 함께 배출 안내. 단 라벨 면적이 용기 표면의 50% 이상이면 라벨 재질도 표기

합성수지 재질 중 용기·트레이형은 '플라스틱', 필름·시트형은 '비닐류'로 구분합니다.

## 4. 자주 하는 실수

**① 뚜껑 마크 누락** — 본체에만 마크를 붙이고 뚜껑 표기를 빠뜨리는 경우입니다. 재질이 다른 뚜껑은 반드시 별도 표기가 필요합니다.

**② 라벨 재질 미표기** — 라벨 면적이 넓은데(용기 표면 50% 이상) 라벨 재질 마크를 빼는 경우입니다.

**③ 마크 위치 혼동** — 뚜껑 마크를 병 본체에만 몰아서 표기하는 경우입니다. 각 구성 요소에 해당하는 마크는 해당 부위에 인접하게 표기하는 것이 원칙입니다.

## 5. 복합 포장재 표시 체크리스트

✅ 포장재 구성 요소별 재질 파악 (본체·뚜껑·내장재·라벨)

✅ 각 재질에 맞는 분리배출 마크 선택

✅ 본체·뚜껑·내장재 각각 마크 표기 (같은 재질도 생략 불가)

✅ 일괄표시 적용 시 모든 구성부분 재질명 함께 기재

✅ 라벨 면적 50% 이상 시 라벨 재질 추가 표기

✅ 소비자가 분리 방법을 인지할 수 있는 위치 선택

## 6. 자주 묻는 질문

**Q. 본체와 뚜껑 재질이 같으면 마크 하나만 붙여도 되나요?**
원칙적으로 각 구성 부분의 재질을 모두 표시해야 합니다. 같은 재질이어도 생략 예외는 없으며, 주요 부분에 표시하고 나머지를 일괄표시로 함께 기재하는 방식이 가능합니다.

**Q. 일괄표시는 아무 때나 쓸 수 있나요?**
지침 제6조의 조건을 충족할 때 가능합니다. 세부 기준이 별도로 규정돼 있지 않아 여건에 맞게 기재하되, 모든 구성부분 재질을 빠짐없이 적어야 한다는 원칙은 동일합니다.

**Q. 수입 제품에 외국 분리배출 마크가 각인돼 있어요.**
각인되어 정정이 어려운 경우에는 외국 표시와 국내 표시를 병행하는 등의 방법이 안내되고 있습니다. 구체적 적용은 관할 기관·한국환경공단에 확인하는 것이 안전합니다.
